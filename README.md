# BridgePlay downloads

Official, Apple-notarized downloads of [BridgePlay](https://bridgeplay.app) for Mac.

**[Download the latest BridgePlay.dmg](https://github.com/BridgePlay/downloads/releases/latest/download/BridgePlay.dmg)**

Every version is listed under [Releases](https://github.com/BridgePlay/downloads/releases). An installed copy of BridgePlay updates itself; you only need this page for a first install.

Each release also carries `BridgePlay-runtime-src-<version>.tar.xz`, the corresponding source of the Windows compatibility runtime bundled with the app, as that runtime's licence requires. The notices for every bundled component are at [bridgeplay.app/notices](https://bridgeplay.app/notices).

The BridgePlay app itself is not open source: this repository holds release files only. For help, see [bridgeplay.app](https://bridgeplay.app).
